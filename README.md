# mirofish-cloud-ops

A wrapper around the real [MiroFish](https://github.com/666ghj/MiroFish) that runs on any laptop: the LLM is Google Gemini (API key) and agent memory is Zep Cloud. No GPU, no Ollama, no large RAM.

> **This version deliberately weakens privacy.** Seed-derived content (the pseudonymised seed, personas, simulation posts, reports) is sent to Google and to Zep. A leak gate blocks uploads that contain your listed sensitive terms, emails, phone numbers or long digit strings, but it cannot make the content private. Nothing here is validated against real outcomes.

**Status:** Phase 0 (repository and safety rails). Install and usage instructions come in Phase 7.

## Safety rails already in place

- `.gitignore` excludes keys, `.env` files, `ops/config/sensitive_terms.txt`, seeds, mappings, run outputs and the upstream clone.
- A pre-commit hook (`.githooks/pre-commit`) blocks commits containing key-shaped strings, private files, or any term in your local `sensitive_terms.txt`. It uses gitleaks plus built-in rules. Enable it after cloning:

  ```bash
  git config core.hooksPath .githooks
  python ops/tools/install_gitleaks.py     # pinned, checksum-verified, into .tools/ (git-ignored)
  ```

- The same scan runs over the full history in CI.

## Templates

| File | Copy to (git-ignored) | Purpose |
|---|---|---|
| `.env.example` | generated by bootstrap | MiroFish settings; keys come from the environment or OS keychain |
| `ops/config/sensitive_terms.example.txt` | `ops/config/sensitive_terms.txt` | Your real names, companies, counterparties for the leak gate |
| `ops/config/limits.example.yaml` | `ops/config/limits.yaml` | Spend, call, time, round and run limits |
| `ops/config/prices.example.yaml` | `ops/config/prices.yaml` | Per-million-token prices from the provider's current price page |
